# 分页前的事实与因果

适用于跨多年经历、多人贡献交织的汇报，以及给非技术读者解释机制的材料。已定稿的局部样式或错字修改直接制作，不重启取材。

1. 写清受众看完需要理解的一件事，以及他们已知的背景。
2. 从材料提取“问题 → 谁对什么采取行动 → 可观察的变化 → 下一步原因”。真实经历区分个人、团队和工具的贡献，缺失事实标为待补，不编造业绩。
3. 机制说明可用明确标注的示意人物和日常任务，但能力、权限、数据仍需可靠来源。先讲动作和后果，再引入必要术语。
4. 按因果重要性分配页面，不机械均分年份或模块。保留理解变化所需的节点；只有影响主结论时才加入失败分支。
5. 在成品中核对：动作是否真的被展示，箭头和前后顺序是否改变事实，人、AI、团队的贡献能否分辨。已有授权继续制作，不增加审批。

没有真实目标读者反馈时，可以报告事实与结构检查结果，但不能宣称受众已理解。作者认可和模拟读者评审都不能替代真实读者复述。
