# PPT Forge — 低保真蓝图 → AI 精美图

## 核心原则

**先把信息设计清楚，再让 imagegen 负责视觉表现。** 不用 HTML/SVG 手工拼出最终画面。

- **内容作者**：分析材料、规划分页、编写低保真 Markdown。
- **视觉生成器**：根据逐页蓝图生成已锁定宽高比的 raster PNG。
- **用户/审稿人**：确认分页、风格和最终文字准确性。

默认最终产物是整页图片，优点是视觉自由度高；代价是文字、图表和形状不可独立编辑。可编辑 PPTX 不在本 skill 的实现范围内；用户明确需要时，只交付低保真稿和视觉素材，并转交独立的原生 PPTX authoring/export 工具。

## 开局参数

开始前锁定：

| 参数 | 说明 | 示例 |
|---|---|---|
| 风格 preset | 目标视觉语言 | 华为 / 用户提供的自定义 preset |
| 受众 | 谁看 | 部门领导 / CTO / 投资人 / 客户 |
| 场景 | 怎么用 | 大屏汇报 / 会后阅读 / 客户提案 |
| 内容取舍 | 是否允许删减 | 全保留 / 只保留核心亮点 |
| 宽高比 | 贯穿蓝图和最终图片 | 16:9（默认）/ 4:3 / 用户指定 |
| 输出模式 | 决定交付能力 | low-fi only / raster PNG |

没有这些参数，就先做最佳判断并明确写在分页方案里；不要直接批量出图。

## 工作流

1. **内容分析**：读完原始材料，提取核心板块、关键数据、逻辑关系和证据来源。
2. **分页规划**：为每页写清页面类型、唯一主结论和承载元素；先让用户确认分页表。
3. **低保真蓝图**：按 [低保真制作规范](references/ppt-lofi-authoring.md) 为每页画 ASCII 布局并写视觉指引。
4. **风格锁定**：华为风格必须读取 [华为式专业汇报 preset](references/ppt-style-huawei.md)。
   > 若为数据密集型技术汇报（基准表/指标/架构图/多方案对比，且文字需可编辑），改走
   > [华为式 HTML 可编辑 deck 轨道](references/ppt-html-authoring.md)，不用 imagegen 出图。
5. **能力预检**：确认当前宿主提供 image-generation / imagegen 工具；没有时停止在低保真稿交付。
6. **逐页出图**：按已锁定宽高比逐页生成，命名为 `p{N}-{简短描述}.png`，不得一次生成整套拼图。
7. **视觉与文字验收**：逐页核对层级、可读性、文字、数字、单位、来源和跨页一致性。
8. **交付**：展示完整预览并说明输出模式的可编辑性边界。

用户否定方向或连续两轮仍有结构性问题时，回到分页规划或低保真蓝图，不在坏版式上继续缝补。

## 低保真蓝图最低要求

每页必须包含：

- 一句主结论，而不是“情况介绍”之类主题词。
- 证据或数据来源；没有来源的数字不得包装成事实。
- ASCII art 布局，区域大小要反映画面比例。
- 面板内容类型：文字、数据、图表、表格、流程、实拍、概念图或公式。
- 逐页视觉指引：布局、重点、配色、图表和装饰层。

不要用“填满页面”代替信息设计。华为式高密度是结构化承载，不是缩小字号、堆满框线或让所有模块同权。

## Imagegen 交接协议

向图像生成器提供：

1. 低保真 Markdown 文件路径。
2. 当前页编号、标题、唯一主结论和完整文字清单。
3. 目标尺寸：使用开局锁定的宽高比，每页独立图片。
4. 风格 preset 与允许覆盖的品牌色。
5. 输出目录和文件名。

生成约束：

- 不删改事实，不臆造数字。
- 不把装饰做成内容主体。
- 不用一张图承担多页内容。
- 遇到长文本时先压缩表达或切页，不把字号压到不可读。
- 图中所有文字必须经过生成后 OCR/人工逐字核对；错字、伪字或数字错误必须重做。

## 输出模式

### Raster PNG

适合追求视觉效果、快速预览和不可编辑交付。明确告知用户：文字不可搜索，图表不可编辑，后续改字需要重新生成或图像编辑。

### Editable HTML deck

数据密集型技术汇报（基准表、指标定义、架构/数据流图、多方案对比）且文字需精确可改、要导出 PPTX/PDF 时，走 [华为式 HTML 可编辑 deck 轨道](references/ppt-html-authoring.md)：手写华为 preset 版式的 HTML section，文字零伪字、可选中、可改稿，架构图用原生文字 SVG。视觉规整度中等，需自行核算字号地板（≥16px）与溢出。封面/愿景等氛围页仍可走 imagegen 轨道，与本轨道混用；底部总结条、配色、字体必须跨页一致。

### Editable PPTX handoff

本 skill 不实现 PPTX authoring/export。用户需要可编辑交付时，停止在低保真 Markdown、逐页文字清单和可复用视觉素材交付，并转交独立的原生 PPTX 制作工具；不得承诺本仓库会生成可编辑文件。

## 验收门禁

- 每页只保留一个主结论，3–6 个核心信息组。
- 3 秒内能找到标题、主结论和关键数字。
- 页面密度服从观看距离，不设置“空白越少越好”的机械指标。
- 红色只强调关键结论和数字，不大面积铺满。
- 同一套 deck 的字体、边框、图标、色板和装饰保持一致。
- 所有文字、数字、单位和来源与蓝图逐项一致。
- 交付前把所有页面并排检查，避免单页好看但整套风格漂移。

## 常见错误

| 错误 | 后果 | 修复 |
|---|---|---|
| 没确认分页就批量出图 | 整套返工 | 先审分页表和最复杂的一页 |
| 把“华为风格”理解成塞满红框 | 信息噪声 | 用层级、数据和结构体现专业感 |
| ASCII 蓝图过于含糊 | imagegen 自由发挥 | 画清区域比例和内容类型 |
| 直接相信图片中的文字 | 错字和伪字进入交付 | 对照文字清单逐字复核 |
| 把 PNG 当可编辑 PPT | 后续无法改字改图 | 转交独立的原生 PPTX 制作流程 |
| 所有页面一次生成 | 风格和文字不稳定 | 逐页生成、逐页验收 |
